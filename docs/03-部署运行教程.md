# 部署运行教程

> 适用环境：Windows 10/11（Linux/macOS 命令同理，路径分隔符不同）
> 交付形态：项目目录整体拷贝即可运行 —— **sqlmap 已内置（`tools/sqlmap/`，1.9.8），无需另行下载**。

## 一、环境要求

| 组件 | 版本要求 | 用途 | 检查命令 |
|------|---------|------|---------|
| Python | ≥ 3.11（开发环境 3.13.2） | 后端运行时 | `python --version` |
| Node.js | ≥ 18（开发环境 24.14.0） | 前端构建（仅部署时需要） | `node --version` |
| sqlmap | **已内置，无需安装** | SQL 注入初筛引擎 | 无 |

> 只想运行后端 + 已构建好的前端（`frontend/dist/`）时，可不装 Node.js。

## 二、后端部署

```bat
cd mhszed-sql\backend

:: 1. 创建虚拟环境并安装依赖（唯一需要联网的步骤）
python -m venv venv
venv\Scripts\pip install -r requirements.txt

:: 2. 启动后端（首次启动自动建表 + 生成种子账号 admin/admin123）
venv\Scripts\python -m uvicorn app.main:app --port 8787
```

启动成功标志：控制台输出 `Uvicorn running on http://127.0.0.1:8787`，
浏览器访问 `http://127.0.0.1:8787/docs` 能看到 Swagger 文档。

**默认账号**：`admin / admin123`（首次登录后请立即在系统内修改密码）。

**数据目录**：`backend/data/`（SQLite 数据库、密钥文件、sqlmap 输出、导出报告）。
备份该目录即备份全部任务/证据/审计数据；删除该目录 = 恢复出厂。

## 三、前端部署

### 方式 A：开发模式（调试用）

```bat
cd mhszed-sql\frontend
npm install
npm run dev          # http://localhost:5173，已配代理转发 /api → 8787
```

### 方式 B：生产模式（推荐）

```bat
cd mhszed-sql\frontend
npm install
npm run build        # 产物在 frontend/dist/
```

`dist/` 为纯静态文件，可由任意 Web 服务器托管（Nginx / IIS / `python -m http.server`），
需将 `/api` 反向代理到后端 8787 端口。开发模式下 Vite 已内置该代理。

## 四、配置

启动后登录系统，进入 **扫描配置** 页：

1. **授权范围**（必填）：添加 IP/域名范围。**只有落在授权范围内的目标才允许测试**，
   未授权目标启动任务时返回 403（安全管控硬约束）。
2. **AI 接入**（可选）：填 OpenAI 兼容接口的 Base URL / API Key / 模型名
   （如 `https://api.deepseek.com/v1` + `deepseek-chat`）。
   API Key 加密存储、界面永不回显。**未配置时自动降级内置规则引擎**，全流程仍可跑通。
3. **SQLMap 路径**（可选）：留空即用项目内置 `tools/sqlmap/`；也可指向本机其他 sqlmap。

## 五、自带测试靶站（演示/验收用）

项目内置演示站点（含已知注入点，仅供本系统功能验证）：

```bat
cd mhszed-sql\backend
venv\Scripts\python tests\demo_site.py        # 127.0.0.1:8899
```

授权范围添加 `127.0.0.1` 后即可对该靶站发起完整测试任务。

## 六、冒烟测试（验收）

四个前置条件：后端(8787)、演示靶站(8899) 已启动。

```bat
cd mhszed-sql\backend
venv\Scripts\python tests\smoke_1.py            :: 14 项：授权/采集/链路还原
venv\Scripts\python tests\smoke_2.py            :: 18 项：WAF/研判降级/复核/知识库（自动临时清空并恢复 AI 配置）
venv\Scripts\python tests\smoke_3.py            :: 18 项：端到端全链路含真实 sqlmap（约 3-8 分钟）
venv/Scripts\python tests\smoke_4_deploy.py     :: 12 项：部署自检，无需启动服务，离线可跑
```

全部输出 `通过 N / 失败 0` 即验收通过。

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 启动任务返回 403 | 目标不在授权范围，扫描配置页添加范围 |
| 研判显示「规则引擎降级」 | 正常：未配置 AI key 时的设计行为 |
| sqlmap 子任务全部 error | 检查 `backend/data/sqlmap/job_*/` 输出目录日志；确认内置 `tools/sqlmap/sqlmap.py` 完整 |
| 前端接口 404 | 后端未启动或代理未生效：确认 8787 在跑、Vite dev 模式自动代理 |
| 报告导出为 TXT | PDF 依赖 simhei 字体，缺失时自动降级 TXT（内容一致） |

## 八、安全提醒

- 本系统仅用于**已授权**的安全测试；授权范围校验、限速、熔断、写接口探测限制
  （禁 UNION 脱数/禁堆叠）均为内置管控，**不得**以任何方式绕过后用于未授权目标。
- `backend/data/` 含任务情报与加密密钥，**严禁**提交公开仓库或放入公共云盘。
