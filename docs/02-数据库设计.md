# mhszed-sql · 数据库设计文档

> 版本：v1.0（2026-10-13）· 数据库：SQLite（SQLAlchemy ORM，方言隔离，可切换 PostgreSQL）
> 库文件位置：`backend/data/scanner.db`（运行时自动创建）

## 设计总览

```
users ──┬── audit_logs（操作者）
        │
auth_scopes（授权范围）── tasks（扫描任务，状态机）
                              │
        ┌─────────────────────┼──────────────────────┐
        │                     │                      │
  endpoints（接口）      waf_profiles            scan_jobs（探测子任务）
    │  └ chain_id            │                      │ sqlmap / ai_probe
    │                        │                      │
business_chains       risk_assessments ── review_actions（人工复核）
（业务会话链）            │
                          │
                    vulnerabilities（漏洞）
                          │
                    evidences（证据链）
                          │
              kb_payloads / kb_false_positives（知识库回流）
```

共 **16 张表**。约定：
- 主键统一 `id INTEGER PRIMARY KEY AUTOINCREMENT`
- 时间戳统一 `created_at` / `updated_at`（TEXT，ISO8601 UTC）
- JSON 字段用 TEXT 存 JSON 字符串（SQLite 无原生 JSON 类型；SQLAlchemy 用 `JSON` 类型自动序列化，切 PG 时映射 jsonb）
- 所有删除一律软删除（`deleted_at` 字段），证据表永不删除

## 1. users（用户）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| username | TEXT UNIQUE NOT NULL | 登录名 |
| password_hash | TEXT NOT NULL | bcrypt |
| role | TEXT NOT NULL | `admin` / `operator`（复核权限区分） |
| is_active | INTEGER DEFAULT 1 | |
| last_login_at | TEXT | 登录日志冗余展示 |

## 2. auth_scopes（授权范围）

> 任务的攻击面白名单。**任务启动前置校验：目标必须命中此表**。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| name | TEXT NOT NULL | 授权项目名（如"XXSRC 2026Q4"） |
| scope_type | TEXT NOT NULL | `domain`（精确）/ `wildcard`（*.example.com）/ `ip` |
| scope_value | TEXT NOT NULL | 值 |
| note | TEXT | 授权凭证/工单号引用 |
| expires_at | TEXT | 授权过期时间，过期后任务拒绝启动 |
| created_at / updated_at / deleted_at | | |

索引：`(scope_type, scope_value)`

## 3. tasks（扫描任务）

> 状态机唯一事实源。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| name | TEXT NOT NULL | 任务名 |
| target | TEXT NOT NULL | 目标（URL/域名，启动时校验 ∈ auth_scopes） |
| auth_scope_id | INTEGER FK→auth_scopes | 命中的授权范围 |
| status | TEXT NOT NULL | `pending` / `collecting` / `scanning` / `review` / `done` / `terminated` / `paused_circuit`（熔断暂停） |
| collect_mode | TEXT NOT NULL | `static` / `burp` / `both` |
| scan_config | JSON | 扫描配置快照（强度/并发/熔断阈值/引擎开关/绕过策略，见 §11） |
| progress | JSON | 各阶段进度 `{stage, done, total, current_step}` |
| error_message | TEXT | 终止/熔断原因 |
| started_at / finished_at | TEXT | |
| created_by | INTEGER FK→users | |

索引：`(status)`、`(target)`

## 4. endpoints（接口）

> 归一后的接口主表。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks NOT NULL | |
| source | TEXT NOT NULL | `crawler` / `burp` / `manual` |
| dedup_hash | TEXT NOT NULL | 归一指纹（method+路径模板+参数结构 哈希），任务内唯一 |
| method | TEXT NOT NULL | GET/POST/... |
| path | TEXT NOT NULL | 归一后路径（数字/UUID 参数替换为模板占位 `{id}`） |
| raw_path | TEXT | 原始路径样本 |
| host | TEXT NOT NULL | |
| params | JSON | `[{name, location(query/body/path), type, sample_value, required}]` |
| headers | JSON | 采集时请求头样本（脱敏后） |
| read_write | TEXT NOT NULL | `read` / `write`（GET/HEAD→read，POST/PUT/DELETE/PATCH→write，结合语义修正） |
| chain_id | INTEGER FK→business_chains | 所属业务链 |
| chain_inferred | INTEGER DEFAULT 0 | 链路是否为推断（1=推断，写接口探测需更严判据） |
| burp_seen_at | TEXT | Burp 首次捕获时间 |
| created_at | | |

索引：`(task_id, dedup_hash) UNIQUE`、`(task_id, read_write)`、`(chain_id)`

## 5. business_chains（业务会话链）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks NOT NULL | |
| name | TEXT | 链路名（如"登录→浏览商品→下单"） |
| reconstruct_method | TEXT NOT NULL | `referer` / `token_derive` / `temporal_cluster`（三级降级策略） |
| confidence | REAL NOT NULL | 链路还原置信度 0~1（referer=0.95, token=0.8, temporal=0.5） |
| node_ids | JSON | 有序 endpoint id 列表 |
| sample_session | JSON | 还原依据样本（referer 链 / token 关系） |

索引：`(task_id)`

## 6. waf_profiles（WAF 指纹画像）

> 任务级（同目标通常同 WAF，但按 host+任务 记录）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks NOT NULL | |
| host | TEXT NOT NULL | |
| has_waf | INTEGER NOT NULL | 0/1 |
| product | TEXT | 产品名：`modsecurity` / `aliyun` / `tencent` / `safedog` / `d_shield` / `bt` / `safeline` / `cloudflare` / `f5` / `unknown` |
| product_confidence | REAL | 产品判定置信度 |
| block_behavior | JSON | 拦截行为画像：`{status_code, page_fingerprint_hash, headers:[{name,value}], block_keyword}` |
| probe_history | JSON | 探针请求/响应摘要（无害探针，不含攻击 payload） |
| bypass_suggestions | JSON | 系统建议的绕过策略标签列表 |
| created_at | | |

索引：`(task_id, host)`

## 7. risk_assessments（AI 风险研判）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| endpoint_id | INTEGER FK→endpoints NOT NULL | |
| task_id | INTEGER FK→tasks NOT NULL | 冗余，加速列表查询 |
| risk_score | REAL NOT NULL | 0~100 |
| confidence | REAL NOT NULL | 0~1，决定人在回路分流 |
| route | TEXT NOT NULL | 研判结论路由：`auto_pass`（≥0.9）/ `manual_review`（0.6~0.9）/ `suspicious`（<0.6，直接深测） |
| reasons | JSON | 研判理由列表（含命中/未命中误报库负样本说明） |
| model_info | JSON | `{provider, model, tokens_used}` |
| kb_negatives_hit | JSON | 命中的误报样本 id 列表（负样本检索留痕） |
| created_at | | |

索引：`(task_id, route)`、`(endpoint_id)`

## 8. review_actions（人工复核）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks | |
| target_type | TEXT NOT NULL | `assessment`（研判复核）/ `vulnerability`（漏洞确认） |
| target_id | INTEGER NOT NULL | 对应表 id |
| action | TEXT NOT NULL | `confirm`（确认）/ `false_positive`（误报）/ `adjust`（修正评分） |
| adjusted_score | REAL | action=adjust 时的新分值 |
| comment | TEXT | 人工备注 |
| reviewer_id | INTEGER FK→users | |
| reviewed_at | TEXT | |

索引：`(task_id, target_type)`、`(target_type, target_id)`

## 9. scan_jobs（探测子任务）

> 流水线两引擎的执行记录。一个接口可产生多条（往返轮次）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks NOT NULL | |
| endpoint_id | INTEGER FK→endpoints NOT NULL | |
| engine | TEXT NOT NULL | `sqlmap` / `ai_probe` |
| round | INTEGER DEFAULT 1 | 流水线往返轮次（上限默认 2） |
| status | TEXT NOT NULL | `queued` / `running` / `finished` / `timeout` / `killed` / `error` |
| result_class | TEXT | 结果分类器输出：`vuln_confirmed` / `no_vuln` / `waf_blocked` / `inconclusive` / `timeout` |
| request_meta | JSON | sqlmap：`{pid, cmd_args_safe(脱敏), output_file, exit_code}`；ai_probe：`{payloads:[...], verdicts:[...]}` |
| ai_payloads | JSON | AI 生成Payload 数组，每条含 `{payload, vector, expected_criteria(预期判据), actual_result}` |
| bypass_strategy | JSON | 使用的绕过策略标签 |
| started_at / finished_at | TEXT | |
| duration_ms | INTEGER | |

索引：`(task_id, engine, status)`、`(endpoint_id, round)`

## 10. vulnerabilities（漏洞）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| task_id | INTEGER FK→tasks NOT NULL | |
| endpoint_id | INTEGER FK→endpoints NOT NULL | |
| scan_job_id | INTEGER FK→scan_jobs | 来源子任务 |
| vuln_type | TEXT NOT NULL | `sql_injection_boolean` / `sql_injection_time` / `sql_injection_error` / `sql_injection_union` |
| severity | TEXT NOT NULL | `critical` / `high` / `medium` |
| title | TEXT NOT NULL | 展示标题 |
| dbms | TEXT | SQLMap 识别的数据库类型（仅库名/版本，合规红线） |
| vector_count | INTEGER | 命中的不同向量数（≥2 才产出，误报控制闸门） |
| status | TEXT NOT NULL | `pending_review`（默认，人工复核）/ `confirmed` / `false_positive` |
| hardening_advice | JSON | 场景化加固建议（按漏洞类型+DBMS+框架生成） |
| created_at | | |

索引：`(task_id, status)`、`(endpoint_id)`

## 11. evidences（证据链）

> 只追加不修改（`updated_at` 恒等于 `created_at`），永不删除。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| vulnerability_id | INTEGER FK→vulnerabilities NOT NULL | |
| evidence_type | TEXT NOT NULL | `request` / `response` / `payload` / `waf_info` / `chain_info` / `console_log` |
| seq | INTEGER NOT NULL | 同一漏洞内时序 |
| content | TEXT NOT NULL | 原文（完整请求/响应包等） |
| meta | JSON | `{http_status, bytes, elapsed_ms, sanitized(bool)}` |
| sha256 | TEXT NOT NULL | content 哈希（完整性） |
| created_at | | |

索引：`(vulnerability_id, seq)`

## 13. kb_false_positives（知识库·误报样本库）

> AI 研判前置负样本检索的数据源。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| endpoint_signature | TEXT NOT NULL | 接口归一指纹（命中即疑似误报） |
| response_signature | TEXT NOT NULL | 响应特征指纹（状态码+页面结构哈希） |
| reason | TEXT NOT NULL | 误报原因（如"WAF 412 页面误判" / "业务正常报错页"） |
| source | TEXT NOT NULL | `auto_feedback` / `manual` |
| source_review_id | INTEGER FK→review_actions | 回流来源复核记录 |
| hit_count | INTEGER | 被负样本检索命中次数 |
| created_at / deleted_at | | |

索引：`(endpoint_signature)`、`(response_signature)`

## 14. audit_logs（审计日志）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| user_id | INTEGER FK→users | 操作者（系统动作为 NULL 或专用 system 账户） |
| action | TEXT NOT NULL | 枚举：`login` / `logout` / `task_create` / `task_stop` / `scan_start` / `scan_request`（每个带payload请求）/ `review_submit` / `kb_edit` / `report_export` / `config_change` / `circuit_break` / `auth_reject` |
| resource_type / resource_id | TEXT / INTEGER | 操作对象 |
| detail | JSON | 详情（含来源 IP） |
| prev_hash / hash | TEXT | 链式哈希（防篡改：hash = SHA256(prev_hash + 内容)），可选启用 |
| created_at | TEXT NOT NULL | |

索引：`(user_id, created_at)`、`(action)`、`(created_at)`
